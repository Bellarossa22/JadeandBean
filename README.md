# Kopi Luma — Website Penjualan Kopi Estetik

Proyek statis sederhana untuk demo toko kopi dengan desain estetis.

Cara menjalankan secara lokal:

1. Buka terminal di folder proyek.
2. Jalankan server statis singkat (Python 3):

```bash
python3 -m http.server 8000
```

3. Buka `http://localhost:8000` di browser.

File utama:
- index.html — halaman utama
- styles.css — gaya estetis
- script.js — interaktivitas kecil (toast)
